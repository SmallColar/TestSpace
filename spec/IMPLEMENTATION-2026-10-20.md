## 替换或移除的旧实现

- 移除了“创建任务立即启动流水线”。任务现在先保存草稿，用户明确点击“开始录制”后才启动浏览器 Agent。
- 移除了任务流水线上的逐批确认、公共变量候选确认及旧式回退/重跑任务入口。现在的流程是保存场景、生成用例草稿、明确保存所选用例。
- 移除了编排规则和用例的 `/{id}`、运行详情中的 `/{id}` 路径；ID 统一放在 query 或 body。
- 移除了本期不在需求中的假运行/环境管理模块、对应前后端文件和页面组件。它原先只模拟执行，没有调用真实自动化平台。
- 移除了旧的断言渲染、报告预览、依赖分析、历史用例检索等未进入当前产品流程的 Agent 工具；AI 录制与 AI 用例生成使用独立的 ChatClient 和职责范围。
- 移除了旧文本启发式用例上传解析入口，改为上传后由 AI 抽取接口级顺序；支持 XMind（content.json/content.xml）、TXT、Markdown、JSON。

数据库使用 `ddl-auto: update`，所以移除 Java Entity 不会自动删除既有数据库表。本轮仍保留旧确认记录、报告及公共变量的实体/Repository，用于删除旧任务时清理已有记录；它们没有对应的新 UI 或 API。

## 当前主要链路

1. 任务列表使用 `/api/tasks`；普通用户只读写自己的任务，admin 可看全部任务。复制只复制名称以外的录制配置，不复制录制结果、规则或用例。
2. 创建任务保存名称、网址、探索目标与要求提示词及 Provider，不启动流程。
3. `/api/tasks/recording/start` 启动任务级 AI Agent。Agent 已在 Playwright 页面上操作，采集相应网络请求，同一段探索提示词在采集后筛选接口；保存前脱敏常见密码、令牌、Authorization、Cookie 和 API Key 字段。
4. 编排可以从当前录制接口新建多个场景、直接加入历史规则或让 AI 推荐历史规则。历史规则可拖拽调整后另存；更新自己拥有的历史规则时同时为当前任务创建独立场景副本。
5. 上传用例分析只产生接口级顺序，不提供或推测入参、前置、后置信息。
6. 用例生成结果按大场景分组，公共参数置顶，每个接口步骤包含输入格式、前置和后置字段。生成只存为任务草稿；保存后写入用例库并请求平台同步。
7. 用例库详情按接口行展开，入参/前置/后置分三个 Tab；输入展示支持 JSON、表单字段和文件元信息。

## 配置和限制

- 需要配置 `SPRING_AI_OPENAI_API_KEY` 及可用的 OpenAI 兼容聊天模型；没有密钥时 AI 录制、上传分析、历史规则推荐和用例生成均无法执行。
- 平台同步地址通过 `TESTPILOT_PLATFORM_SYNC_URL` 配置。默认 mock 服务只存在内存中，重启会清空；生产平台需配置真实接收端并确认其字段映射。
- 浏览器录制依赖 Playwright MCP 能访问目标站点。登录、验证码、复杂弹窗或需要外部凭证的流程，需在用户给出的探索目标/站点环境中解决；本轮未实现浏览器会话接管和人工验证码流程。
- 用例相似度及历史用例覆盖分析还未接入本轮 AI 生成链路；保存使用稳定草稿键避免同一草稿重复入库，尚未做语义相似用例的冲突处理 UI。
- 任务/规则/用例列表当前以数组一次返回，筛选在前端完成；API SPEC 中的服务端分页尚未实现。
